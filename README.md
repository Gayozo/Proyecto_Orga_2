## 📌 Descripción del Proyecto

El sistema está orientado a optimizar la gestión operativa y de autogestión en los diferentes eslabones de la cadena de valor de una empresa láctea:
* Registro y trazabilidad del ingreso de materia prima (recepción de leche cruda).
* Control de stock de productos elaborados y derivados lácteos.
* Gestión de pedidos, distribución a mayoristas y puntos de venta.
* Manejo de logística inversa (devoluciones por avería, vencimiento o productos defectuosos).

---

## 🛠️ Requisitos Previos

Antes de ejecutar el proyecto localmente, asegúrate de contar con:
* [Node.js](https://nodejs.org/) (versión LTS recomendada).
* [PostgreSQL](https://www.postgresql.org/) (o el motor de base de datos acordado).
* [Git](https://git-scm.com/) configurado en tu equipo.
